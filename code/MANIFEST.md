of the original file (computed when it was copied; the originals were not modified), and the changes made

expected result fails, and a negative control exits 0 only when it is caught. They change no computation and
no printed output; where a value was computed inside a `print`, it is now stored in a variable first and
printed unchanged. Checks that already stop on a failed `assert` (or already set their exit status) were not
changed.

run_full.sh), the launchers `run_*.py`, and the `logs/` and `out/` folders are new.
